### 💡 فكرة المشروع
تكتك بالي هو حل لمشكلتين:
1.  **نقل الركاب:** ربط الركاب بأقرب سائق تكتك بسرعة وأمان.
2.  **توصيل سريع:** توصيل الطلبات الخفيفة (مطاعم، صيدليات، مستندات، أغراض صغيرة) عن طريق سائقي الدراجات بأسرع وقت.

### ✨ المميزات
#### للركاب:
- 📍 اطلب تكتك لأقرب مكان بدوسة زر
- 💰 اعرف سعر الرحلة قبل لا تطلب
- 🔴 تتبع مباشر للتكتك على الخريطة

#### للتوصيل السريع:
- 🏍️ توصيل بالدراجة للطلبات الخفيفة والسريعة
- ⚡ توصيل خلال دقائق داخل المنطقة
- 📦 تتبع طلبك لحظة بلحظة

#### عام:
- ⭐ تقييم السائقين
- 💬 دردشة مباشرة بين العميل والسائق
- 🔔 إشعارات فورية

### 📦 محتويات المستودع
